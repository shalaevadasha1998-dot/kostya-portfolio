# kostya portfolio

первая версия сайта-портфолио кости-дизайнера.

## структура

- `index.html` — главная
- `styles.css` — визуальная система и адаптив
- `script.js` — микроанимации

## запуск

открой `index.html` локально или опубликуй репозиторий через github pages.

## статус

v0: собран визуальный каркас с кейсами paysenger, hazeflow, «эйфория», «дворец впечатлений», smile park и gomining. сейчас карточки сделаны как графические плейсхолдеры; реальные изображения кейсов добавим следующим проходом вместе с финальными текстами и контактами.
