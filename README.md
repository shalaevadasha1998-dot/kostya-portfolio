# kostya portfolio

первая версия сайта-портфолио кости-дизайнера.

## структура

- `index.html` — главная
- `styles.css` — визуальная система и адаптив
- `script.js` — микроанимации
- `assets/` — оптимизированные изображения кейсов

## запуск

открой `index.html` локально или опубликуй репозиторий через github pages.

## статус

v0: собран визуальный каркас. тексты, контакты, порядок кейсов и отдельные case-study страницы будут уточняться после ответов кости.
